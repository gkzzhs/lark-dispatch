## 安全口径

- 真实创建任务、写文档、发送消息必须等待用户明确确认。
- 重复分发检查先看 `docs/assets/live-runs.jsonl`，再搜索同会议标题或妙记 token 的历史分发报告。
- 文档创建遇到 `folder locked` 时只做短重试，并保持串行创建，避免并发写入冲突。
- bot IM 是应用身份权限，不能只看 user `lark-cli auth check`；以飞书开发者后台、bot dry-run 和真实发送返回为准。
- 收尾检查 `openclaw cron list` 为 `No cron jobs.`，历史 disabled cron 记录仅作为证据留存，不会主动触发。
