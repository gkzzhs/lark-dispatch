# 官方模型适配说明

本项目为飞书 AI 校园挑战赛 2026 OpenClaw 赛道参赛作品，模型调用通过 OpenClaw 运行环境完成，核心工作流不绑定单一模型。根据导师确认，比赛允许使用其他模型；本项目在主动触发配置中保留显式模型参数，便于演示环境稳定复现。

## 模型配置

### 主动触发指定模型
第三周期正式 cron 验证使用：

`deepseek/deepseek-chat`

历史参数验证曾使用 `zai/glm-5-turbo` 创建 cron job，但后续 run 因本机未配置 zai provider API key 失败，该结果已记录为失败/降级证据，不计为成功 E2E。

### 模型适配说明
1. 所有 AI 分析、信息提取、内容生成均通过 OpenClaw Agent 执行，不在项目中硬编码第三方 API Key
2. cron 主动触发命令通过 `--model deepseek/deepseek-chat` 显式指定第三周期验证模型，避免受默认模型漂移影响
3. 若演示环境默认模型不同，可继续使用 cron 的 `--model` 参数固定演示模型；也可按比赛允许范围切换到其他可用模型

## 模型验证命令

### 查看当前模型状态
```bash
openclaw models status --plain
```

### 查看可用模型列表
```bash
openclaw models list
```

### 验证输出示例
2026-04-25 环境曾验证输出：
```
zai/glm-5-turbo
```

2026-04-28 当前本机环境输出：
```
deepseek/deepseek-chat
```

这说明默认模型会随环境变化。项目文档和 Demo 以第三周期证据登记表中的实际验证模型为准：正式 cron 配置和 run history 使用 `deepseek/deepseek-chat`；`zai/glm-5-turbo` 仅作为历史参数验证和失败记录保留。

## 适配说明
- 本项目 prompt 以中文会议纪要的信息提取、分类、去重和分发确认为核心，适合支持长文本理解和结构化输出的模型
- 当前主动触发 Demo 使用 `deepseek/deepseek-chat` 作为显式模型参数；若切换其他模型，需要重新抽样验证提取准确率，并在效果报告中标注
- 模型切换不会改变飞书 CLI 分发链路，但会影响待办/决策/知识要点的提取质量，因此效果报告需标注测试时的模型环境
