# 官方模型适配说明

本项目为飞书 AI 校园挑战赛 2026 OpenClaw 赛道参赛作品，**完全基于 OpenClaw 官方模型配置运行**，未使用任何第三方大模型服务。

## 模型配置

### 默认使用模型
`zai/glm-5-turbo`

### 模型适配说明
1. 所有 AI 分析、信息提取、内容生成都通过 OpenClaw 官方提供的模型接口完成
2. 严格遵循 OpenClaw 技能开发规范，模型调用完全基于官方标准能力
3. 无需额外配置 API Key 或其他模型参数，开箱即用

## 模型验证命令

### 查看当前模型状态
```bash
openclaw models status --plain
```

### 查看可用模型列表
```bash
openclaw models list
```

### 验证输出示例
执行 `openclaw models status --plain` 实际输出：
```
zai/glm-5-turbo
```
