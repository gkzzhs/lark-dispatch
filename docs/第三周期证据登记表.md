## 5. 已知风险

| 风险 | 影响 | 处理方式 |
|---|---|---|
| cron isolated session 读取不到飞书配置 | cron 自动触发失败 | 记录失败日志，降级为手动触发同一 Skill 流程 |
| IM self-send 或跨租户限制 | 决策通知无法真实送达 | 记录错误，分发报告标记为跳过或失败 |
| 会议数据敏感 | 无法公开展示 | 使用脱敏会议或公开演示会议纪要 |
| 权限不足 | 任务/文档/消息创建失败 | 记录权限错误，保留可追溯降级结果 |
| cron run 可能返回 not-due | 无法重复手动触发同一任务 | 记录 not-due 输出，调整 schedule / 新建临时 job / 手动触发同一 Skill 作为降级验证 |
| cron isolated session delivery 可能 not-delivered | 任务执行成功但消息未送达 | 记录 lastRunStatus 与 lastDeliveryStatus，区分“执行成功”和“投递失败” |
| isolated session 可能读取不到 Feishu appId/appSecret | cron 自动触发无法访问飞书配置 | 记录原始错误，确认是否为 isolated session 环境差异，降级为手动触发同一 Skill 流程 |
